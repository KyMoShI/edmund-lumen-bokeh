# 浅色界面视觉梯度规范

本文规定浅色界面的文字角色、边框、圆角、间距与控件外框。原稿几何取自 PDF，工作区采用 `1/3` 参考比例。通用数值、源测量与运行修订分列在[设计参数清单](light-reset.scale.json)。各页位置见[页面规范](LIGHT-RESET.md)，精确矩形见[欢迎页布局](../../app/assets/welcome/layout.json)和[工作区布局](../../app/assets/workspace/layout.json)。

## 单位与换算

为分开管理原稿测量与运行绘制，本规范采用**设计单位 du**，与 PDF 原始 pt 的数值相同。du 表示画板几何量，不是 Qt 字体点数、逻辑像素或设备物理像素。

`运行逻辑尺寸 = 设计值 × s_ui`。工作区参考比例已确定为 `s_ui = 1/3`，对应 **1365.333 × 720 逻辑像素**；不得按字体、圆角、描边分别选取缩放比例。以下 `1/3` 列为当前工作区参考换算，`1/2` 列仅保留数值示例，不代表第二套运行比例，也不指定最小窗口尺寸。

欢迎页 UI 比例取可用宽度 / 4096 与高度 / 2160 的较小值；品牌、START、NEXT 分别使用左下、右下、右上锚点，绘制与命中共用变换。场景与圆形几何按高度 / 2160 等比缩放并裁切；波纹、参考线及底部几何独立适配，不再使用整页居中留白。工作区控件仍使用固定逻辑字号、宽度及列网格，右侧卡片高度和预览内部比例则独立调整。

| 项目 | 原始设计量 | s_ui = 1/3 | s_ui = 1/2 |
| --- | ---: | ---: | ---: |
| 4096 × 2160 画板 | 4096 × 2160 du | 1365.333 × 720 逻辑 px | 2048 × 1080 逻辑 px |
| 普通控件文字 | 35.7778 du | 11.9259 逻辑 px | 17.8889 逻辑 px |
| 面板边框 | 2 du | 0.6667 逻辑 px | 1 逻辑 px |
| 面板圆角半径 | 50 du | 16.6667 逻辑 px | 25 逻辑 px |

界面缩放比例一经选定，普通窗口拖动缩放不重新计算控制区的 `s_ui`；预览视口和背景按已确认的规则适配。系统 DPI 缩放由 Qt 处理，布局值不再额外乘设备像素比。字体使用像素尺寸或等效的浮点绘制尺寸，不把 du 直接传入字体点数接口。细轮廓保留必要的抗锯齿，不以“至少 1 个逻辑像素”强制加粗。

当前工作区的[布局实现](../../app/workspace.py)以源锚点乘 `1/3`，右侧卡片固定宽度，高度随可用区及各自比例变化；[控件实现](../../app/workspace_controls.py)保持字号、内边距和列网格。背景采用独立锚定策略，见[背景数据](../../app/assets/workspace/background.json)；预览分区可调整，图片保持比例及各自缩放、平移。面板九宫格只伸展直边区域，保留源圆角与边框厚度。设计清单分开记录源测量、表单及窗口修订，代码不直接读取其中每个通用角色。

## 描边梯度与状态

| 角色 | 设计宽度 du | 来源及用途 |
| --- | ---: | --- |
| `border.none` | 0 | 无描边底面、文字标签与黑色主操作底面 |
| `border.control` | 0.75 | 原稿普通下拉及侧栏按钮内外轮廓间距的等效细边 |
| `border.panel` | 2 | 原稿预览、历史设置及参数三大面板 |
| `border.sliderHandle` | 2.5 | 原稿滑块手柄的内外轮廓间距 |
| `border.focus` | 4 | 补充定义的键盘焦点外环；不替换原稿常态描边 |

普通控件的原稿细边以复合填充路径构成，不能从页面继承的 3 / 5 pt 线宽反推其边框。若运行端改用描边绘制，应保持内外轮廓及可见厚度；原稿中有明确形状的控件优先保留路径几何。背景红线及圆弧为 3 du、波纹为 4 du、下拉箭头为 5 du、相机装饰为 6 du，沿用源路径并与 UI 边框档位分离。

`border.none` 明确表示不绘制边框，运行端使用无画笔或不可见状态，不能仅通过将画笔宽度设为 0 表示。零宽画笔可能表示设备最细线；该语义与原稿 hairline 分别保留。

| 状态 | 线宽、几何与反馈 |
| --- | --- |
| 默认 | 使用组件所属描边档位 |
| 悬停 | 保持原线宽及外框尺寸，调整颜色或底面；卡片倾斜遵循动画设置 |
| 按下、选中 | 保持布局尺寸，使用底面或内容状态表达 |
| 键盘焦点 | 绘制独立外环，预留外扩空间；不挤压内容或改变控件外框 |
| 禁用 | 保留字号、几何及线宽，调整颜色和交互状态 |
| 状态结束 | 清除该状态对应的覆盖层；焦点外环在失焦时清除，不因悬停或按下结束而移除仍然有效的键盘焦点 |

描边默认以路径居中理解；使用内描边、外描边或填充轮廓时，必须以最终内外边界验收，不能只比较一个宽度数字。可点击范围、视觉边框和焦点外环分别管理。

上表及状态表保留源测量与补充设计目标。当前工作区常态控件细边约为 0.25 逻辑 px，滑块手柄描边约为 0.85 逻辑 px；键盘焦点反馈由各自控件绘制，部分采用内侧轮廓，尚未统一为 `border.focus` 所定义的 4 du 独立外环。焦点位置、独立弹窗及全部状态轮廓仍需按上述目标继续核对，不能仅以资源接入或换算比例确定代替状态验收。

## 圆角半径与形态

圆角使用半径 **r** 表示，单位 du，经统一比例换算成逻辑 px；不使用角度表示，也不把 `999` 作为验收半径。

| 角色 | 半径 | 用途 |
| --- | ---: | --- |
| `radius.square` | 0 | 原稿直角预览占位、矩形标签及信息条 |
| `radius.checkbox` | 6.292 du | 原稿复选框 |
| `radius.control` | 14.242 du | 普通下拉、侧栏按钮及新增同类输入 |
| `radius.panel` | 50 du | 三大面板及完成提示容器 |
| `radius.action` | 50 du | 原稿主操作按钮；独立于按钮高度 |
| `radius.pill` | min(W, H) / 2 | 真正的胶囊条；横向为 H / 2，竖向为 W / 2 |
| `radius.circle` | min(W, H) / 2 | 圆点与圆形标记 |

**主操作按钮不能全部改为半高胶囊。** 原稿工作区按钮约 506.682 × 146.051 du、完成页按钮约 383.523 × 110.551 du、欢迎页 `START` 约 901.923 × 259.980 du，均采用 r = 50 du。相同页面中的同级按钮保持相同高度与基线，各页面不强制使用同一高度。

原稿分组标题条高约 64.262 du，端部曲线约有 r = 30 与 32.131 du 两种值，这些源路径不等于完全标准的半高胶囊。当前工作区的表单修订将运行标题统一为高 26 逻辑 px、r = 13 逻辑 px，源测量仍保留。图案、相机插图与品牌标记不作为通用圆角组件。

滑块轨道为 419.144 × 28.484 du、r = 14.242 du；竖向手柄为 28.484 × 56.665 du、r = 14.242 du。滚动条宽 31.094 du、r = 15.547 du。导出使用报告按钮为 253.341 × 73.026 du、r = 36.513 du。这些属于按短边计算的胶囊形态，不能套用主操作固定 r = 50 du 的规则。

## 间距、控件外框与对齐

补充功能采用 6 du 基础步长，允许档位为 **0 / 6 / 12 / 24 / 36 / 48 / 72 / 96 du**。这是新增排版规则，不声称原稿全部对象已经落在该网格上。设计稿中的面板位置、背景图形、按钮锚点和原有内部关系保持原值。

| 角色 | 设计量 | 用途 |
| --- | ---: | --- |
| `space.inline` | 12 du | 相关小元素或文字与标记之间 |
| `space.control` | 24 du | 新增控件内容的水平内边距及相关操作间距 |
| `space.row` | 36 du | 新增参数行之间的净间隔 |
| `space.section` | 48 du | 新增功能组之间的净间隔 |
| `space.panel` | 72 du | 新增面板内容的默认留白 |

原稿普通下拉及侧栏按钮外框高度为 **56.665 du**，在源测量与组件表中保留；它不再直接决定修订后的运行高度。高度包含内容、内边距和描边，不把 QSS `min-height` 直接作为外框高度。单行文本按字体度量垂直居中；多行信息另按行高计算高度，不能强塞进单行框。

滑块的名称列、轨道列和数值列在同一分组内共用列宽与对齐线。下拉箭头、滚动条及焦点外环不得覆盖数值；滚动条使用独立预留列。同一操作行的按钮外框顶底、文字基线及间距共同验收，不依靠阴影边缘判断对齐。

## 实施与验收约束

1. 原稿已有的页面对象按其测量值及路径复现；补充控件复用上述角色，不因整数取整或通用梯度改变指定按钮、背景及品牌几何。
2. 工作区运行参考比例已固定为 `1/3`，对应逻辑像素取整见本文；当前最小窗口及空间不足策略由页面规范记录，不能从另一换算示例推定。页面尺寸约束只由当前页提供，隐藏页面不参与计算。
3. 源图层、运行控件与补充组件分别按其角色检查；新增例外记录用途及依据，避免隐式覆盖。运行值由布局及控件代码维护时，须同步更新清单中的运行映射，保留原稿测量。
4. 检查 100%、150%、200% 系统缩放下的实际字号、字体家族、字重、外框、可见描边和圆角；允许栅格抗锯齿差异，不允许重复进行 DPI 缩放。
5. 检查默认、悬停、按下、选中、禁用及键盘焦点状态；状态变化不移动控件，不截断数值，也不改变指定按钮文案。
6. 离屏回归覆盖源图层组合、实际字重、浮动归位、导出完成页和英文按钮字形。工作区部分控件仍绘制内侧焦点轮廓，实测结果见[浅色界面核对](../../docs/代码检查报告.md#浅色界面核对)。动画时序由运行设置定义。
