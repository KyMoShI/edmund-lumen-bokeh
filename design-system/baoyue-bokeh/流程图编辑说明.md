# 流程图可视化编辑

[工作区流程图.drawio](工作区流程图.drawio)包含「01 主工作区」「02 页面导航」和「03 待填写事项」三页，可使用 diagrams.net 桌面版或[在线编辑器](https://app.diagrams.net/?lang=zh&mode=device)修改。

1. 从设备打开 `.drawio` 文件，在底部标签切换到目标页面。
2. 双击节点修改文字，拖动节点调整位置。拖动节点边缘的连接点可新增或修改连线。
3. 在第三页编辑问题右侧的回答栏，保存为 `.drawio` 文件。
4. 行为发生变化时同步更新 [Markdown 流程图](INTERACTION-FLOW.md)。两份文件分别保存，图形节点的调整不会自动写回 Markdown。

交互决定以 Markdown 中[待填写事项](INTERACTION-FLOW.md#待填写事项)的原始回答及其后已确认的修订为准。调整图形布局无需修改行为说明。
