# 伯爵大光圈模拟 · 桌面界面规范

## 两种工作区

| 项目 | 浅色模式 | 黑夜模式 |
| --- | --- | --- |
| 色彩与结构 | 白底、蓝色交互轮廓、红色结构线。自左向右排列预览、历史与设置、参数三栏 | 深色底面，强调色为金黄 `#F6D05D`，保留可排序的控制卡片 |
| 图像操作 | 工作区底部为 `IMPORT` 和 `EXPORT`，中栏「设置」菜单提供原图对比 | 底部提供导入、原图对比和导出 |
| 面板调整 | 历史与参数卡片可独立调整高度，预览支持左右及上下一对分隔手柄 | 拖动卡片标题，越过相邻卡片中线时换位，靠近滚动边缘时自动滚动，释放后保存顺序 |
| 统计入口 | 参数卡片顶部，或「设置 → 图像直方图」 | 可折叠的直方图卡片 |
| 图像导航 | 滚轮缩放，中键平移，双击适应窗口 | Ctrl + 滚轮缩放，Ctrl + 中键平移，双击复位 |

主题切换保留当前图片、参数、历史及选定的直方图通道。浅色页面的锚点、按钮层级、分组布局和浮动入口见[浅色模式界面规范](LIGHT-RESET.md)，控件尺寸见[视觉梯度规范](VISUAL-SCALE.md)。

## 共享组件与状态

- **字体**使用内置的更纱黑体 SC，常规、半粗、粗体分别为 400、600、700。英文主操作沿用设计稿的指定文案。
- **动画**由共同设置控制。主题切换采用模糊过渡，卡片支持悬停倾斜，小按钮使用按压、悬停及键盘焦点反馈。空画布的鸟群跟随指针，指针离开后向随机目标迁徙，每个粒子具有独立透明度，可启用个体速度差异。
- **页面导航**共用欢迎页和导出完成页。导出设置、模型导入、帮助、消息及浮动面板共用纸面窗口。确认与取消位于固定操作区，文件选择沿用系统对话框。欢迎页和完成页的同名按钮按各自上下文导航，详见[页面流程](INTERACTION-FLOW.md#页面与主要流程)。
- **实现位置**见[浅色工作区](../../app/workspace.py)、[表单控件](../../app/workspace_controls.py)、[直方图](../../app/histogram.py)、[纸面窗口](../../app/design_dialogs.py)和[黑夜主题令牌](../../app/theme/tokens.py)。两种工作区共用[主窗口](../../app/main.py)的处理、会话和历史状态。

## 历史设计与交互记录

- 2026-10-19 的生成方案包含紫色、青色及 Web 交互建议。桌面实现采用 Qt 控件与主题令牌，历史生成方案未作为现行规范。
- 早期黄黑方案将品牌强调色统一为 `#F6D05D`，并使用集中管理的字体、焦点环及按钮状态。后续浅色方案增加红蓝分区、卡片投影及底部品牌区。黄黑色令牌保留于黑夜主题。
- 卡片排序曾分别验证覆盖层变暗、描边、位图副本换位及运动模糊。移动控件上的图形效果缓存曾造成错位；隐藏真实卡片也可能使鼠标释放事件转移。拖动结束与失活状态需统一清理。当前排序以中线判定和边缘滚动为主，早期位图滑动换位动画未恢复。
- 历史视觉记录见[主题对比](preview-compare.png)、[拖动变暗](preview-drag-dim.png)、[描边反馈](preview-drag-edge.png)和[位图换位](preview-slide-ghost.png)。这些图片对应各阶段实现。
