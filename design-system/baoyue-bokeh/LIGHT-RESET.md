# 浅色模式界面规范

视觉基准为项目根目录的 `排版.pdf`，`排版.ai` 补充图层结构与素材。本文规定欢迎页、浅色编辑工作区、导出完成页和二级窗口的外观。两种工作区的差异见[桌面界面规范](MASTER.md)。

页面跳转和交互决策由[交互流程图](INTERACTION-FLOW.md)维护。

字号、字重、描边、圆角、间距及控件外框按[视觉梯度规范](VISUAL-SCALE.md)执行，数值统一记录于[设计参数清单](light-reset.scale.json)。保留原稿测量及路径，表单留白与列网格的后续修订另列为运行规则，不覆盖源数据。欢迎页及工作区均使用独立原稿图层；工作区控件通过运行映射重绘并绑定现有处理状态。

## 设计稿与基准

| 画板 | 内容 | 规范用途 |
| --- | --- | --- |
| 第 1 页 | 欢迎页、品牌区、背景与 `START` / `NEXT` | 品牌、开场布局与背景 |
| 第 2 页 | 编辑界面上的导出完成提示 | 遮罩、背景模糊与弹窗 |
| 第 3 页 | 编辑工作区、设置及主操作 | 主窗口布局与控件样式 |

三个画板均为 **4096 × 2160 pt**，宽高比 **256:135**。工作区使用 `1/3` 的设计单位换算比例，参考尺寸为 **1365.333 × 720 逻辑像素**；历史设置及参数面板保持该比例下的逻辑宽度，高度按可用空间与保存比例调整。PDF 的 pt、设计单位 du 与 Qt 字体点数分开管理，源几何与运行伸缩规则分别记录。

PDF 第 1 页显示完整场景。Illustrator 文件的兼容预览缺少首页软蒙版内容，原生文件仍保留该场景和画板外素材。复核方法、源文件指纹及限制见[设计文件检查记录](设计文件检查记录.md)。

## 色彩

以下为 PDF 基础色值经 sRGB 渲染的近似值。颜色应建立语义令牌；透明度、叠加色、渐变和阴影以原始图层及渲染效果为准。

| 令牌 | 近似值 | 用途 |
| --- | --- | --- |
| `surface` | `#FFFFFF` | 主背景、面板与弹窗底面 |
| `ink` | `#262626` | 主要黑色按钮、标题底条 |
| `text` | `#121212` | 正文及数值 |
| `blue` | `#001EFF` | 面板细描边、滑块、品牌强调及焦点反馈 |
| `blue.soft` | `#808EFF` | 拍摄信息条及辅助区域的底色。信息条正文用色见[当前表单修订](VISUAL-SCALE.md#当前表单修订) |
| `red` | `#FF3D36` | 左侧竖线、辅助几何、警示与强调动作 |
| `placeholder` | `#E6E6E6` | 空预览与直方图共用的浅灰底色。空预览显示白色鸟群，直方图显示白色柱条 |
| `track` | `#B0B0B0` 附近 | 滑块未填充段、滚动条 |

蓝色与红色有不同职责：主交互轮廓和参数进度使用蓝色；红色用于画面结构及特定强调。主要文字使用近黑色，黑色主按钮使用白字。第 1、2 页的红底白字为设计稿中的较大按钮字样；正文和小号控件文案应检查对比度，不能直接沿用低对比组合。

## 字体与文案

- 字体使用 **Sarasa Gothic SC（更纱黑体 SC）**。PDF 中使用 Bold 和 Semibold，字体均以子集形式嵌入；完整资源的检查状态统一见[视觉梯度规范](VISUAL-SCALE.md#字重资源)。
- 字重使用 400 / 600 / 700 三档。参数标签、数值、下拉选项和普通功能按钮统一使用 `text.control`；预览标签、分组标题和页面主操作分别使用独立角色。字号依据 PDF 的有效文字矩阵测量，运行端按统一比例换算，再实测基线和文字边界，不从缩略图推定点数。
- 编辑区域以中文功能名称为主。设计稿中的 `START`、`NEXT`、`EXIT`、`IMPORT`、`EXPORT` 保留指定文字、外框、位置及阴影；2026-11-16 的运行修订移除蓝色字形描边，统一使用白色填充。行为以交互流程图为准，原稿文字轮廓保留在源文件测量中。
- 版本字符串和示例拍摄信息均为数据占位。无照片时，图片信息区保持空白且不可交互；导出地址显示完整路径。导出完成提示的序号为 0–9 的随机数字。

## 页面结构

### 欢迎页

- 白色底面，左侧红色竖线、顶部红色细线、淡蓝波纹及红色圆形几何组成背景；右上角保留蓝色方块。
- 左下区域为蓝色大字母与黑底白色中文品牌条，右下为黑底主按钮，右上为红底次操作。
- 背景几何、插图和文字均保留独立层级。插图按原比例缩放，不进行非等比拉伸。
- 每次启动显示欢迎页。`START` 进入空白工作区并沿用当前参数偏好；`NEXT` 恢复有效图片会话。无记录时进入空白工作区并提示；同进程恢复保留历史，跨启动恢复图片路径、深度、参数、模型及预览选项，以恢复状态建立新历史基线。
- 品牌条与 RE 字标锚定左下，START 锚定右下，NEXT 锚定右上；UI 比例为宽度 / 4096 与高度 / 2160 的较小值。红色场景与两条圆形几何组成独立等比组，按窗口高度缩放、底部对齐，窄窗口裁切两侧。波纹、参考线、蓝色方块和底座分别适配，不再将整页居中留白。绘制与原生按钮命中共享各自锚点，编辑区主题偏好不改变此页外观。场景数据见[欢迎页分层](../../app/assets/welcome/scene.json)。
- 入场使用渐显，先逐字显示「伯爵大光圈」，完成后按实际时间停留 3 秒，清空首句后逐字显示「今天我们要模拟什么」，末尾竖线光标以约 500 ms 间隔闪烁。第二句按原品牌文字矩形适配字号，黑色品牌条及菱形几何不改变。动画总开关或标题开关关闭时直接显示静态第二句及常显白色光标，停止闪烁定时器。
- 按钮保留悬停微移、按下及键盘焦点反馈，无倾斜。高频打字更新在等待及完成状态停止，等待使用单次定时器，光标使用低频定时器；隐藏或导航时取消标题调度。实际截图见[首句与布局](pages/welcome.png)及[提示语状态](pages/welcome-prompt.png)。

### 编辑工作区

按第 3 页画板建立三个横向区域。精确面板、预览、标签、信息框及按钮矩形记录于[工作区布局数据](../../app/assets/workspace/layout.json)，替代缩略图百分比估测。背景、面板外框与投影、三色圆点、点阵、相机装饰、预览标签和主操作均保留独立层；静态示例参数、拍摄信息及灰色占位图不烘焙进背景。

| 区域 | 基准锚点 | 窗口变化规则 |
| --- | --- | --- |
| 预览总面板 | 第 3 页原稿左侧面板与三处预览矩形 | 左上锚点保持；右边界随右侧卡片移动，底边随可用高度变化；内部两处分区可调，图像保持比例 |
| 历史与设置面板 | 第 3 页中间窄面板 | 宽度固定并随右边界平移；高度默认填满可用区，可独立调短；新增高度分配给历史列表，下方设置整体下移 |
| 参数面板 | 第 3 页右侧宽面板 | 宽度固定并随右边界平移；高度默认填满可用区，可独立调短；增减滚动视口高度，参数字号和列网格不缩放 |
| IMPORT / EXPORT | 第 3 页两个主操作外框与共同基线 | 保留原稿图层及等比尺寸；位于普通面板之上 |

- 预览总面板为白底、蓝色细描边、圆角及外阴影。面板内部左侧是原图，右侧上方是效果图、下方是深度图；两处分隔手柄分别调整左右宽度及右列上下高度，默认比例来自源稿。浮动预览的原位占位随分区调整，原画布与图片视图不重建。三个黑底白字标签固定在各自预览左上角。
- 历史与设置面板包含操作历史、主题、动画、帮助、效果范围、预览质量和使用报告入口。设置菜单收纳原图对比、撤销、恢复（重做）、图像直方图及返回欢迎页；历史条目支持直接跳转。
- 右侧参数面板从上至下依次为图片信息、「焦点景深」与「镜头虚化」。「焦点景深」默认收起附加功能，标题使用 ▸ / ▾ 标识收起及展开状态。「镜头虚化」常驻光圈、虚化强度、光斑强度、形状、密度、大小、高性能模式、球差、猫眼压缩、高光补偿及阈值 11 项控制，标题不折叠内容。所有控件与主窗口原有参数双向绑定，继续共用深度模型、渲染和历史状态。独立示意中重复标为「模型选择」的控件对应深度图分辨率，焦点景深中的「光斑密度」示意对应焦点深度。
- 参数卡片顶部框内为灰底白条直方图，右上角仅保留 R / G / B 三个方形按钮；互斥选择，点击已选按钮取消，全部未选时显示亮度。常态黑底白字、选中蓝底白字；图表不绘制标题、坐标文字、通道说明或图例。按钮尺寸及间距见[视觉梯度](VISUAL-SCALE.md#当前表单修订)。下方照片信息条保留 EXIF 四列，无 EXIF 时使用尺寸与格式两列；未导入图片时，绘图区与元数据条均留空，通道按钮禁用并保留选择。相机装饰位于滚动内容末尾，不覆盖参数。统计语义见[操作说明](../../README.md#操作说明)。
- 分组标题、正文、开关和整行操作共享表单内边界；下拉框、滑块轨道与数值采用统一列。历史面板主按钮共享左右边界，预览质量作为标签和操作的两列行。按钮按文字宽高设置留白，完整运行数值及来源见视觉梯度规范，常规状态变化不移动对齐线。
- 右下两个黑色圆角矩形按钮分别对应导入和导出，文字、尺寸、阴影和垂直基线统一，使用 `radius.action` 及工作区主操作外框角色；原稿形态不改为半高胶囊。按钮作为主窗口前景操作层，不被普通卡片遮挡；弹窗及主题过渡层可位于其上。
- 无图片预览采用灰底及白色鸟群粒子。粒子沿用个体透明度、速度差异、指针跟随及迁徙设置。
- 原图、效果图、深度图、历史设置、参数面板、镜头虚化、焦点景深七处均可独立打开。悬停显示浮动入口；独立窗口支持移动和缩放，关闭窗口或恢复操作使部件归位。
- 浅色与黑夜模式可互相切换；黑夜模式保留此前版本的布局。

### 导出完成提示

第 2 页前景已接入图片导出成功回调；导出设置与后台渲染继续使用既有参数和队列。实际界面见[导出完成页](pages/export-completion.png)，源矩形见[完成页数据](../../app/assets/completion/layout.json)。

- 弹窗为白色圆角面板、蓝色细边与柔和外阴影；左上有浅蓝点阵，底部有低对比度背景插图，右上有黑、蓝、红三点装饰。
- 主导出按钮打开独立的导出设置窗口。
- 文件地址使用实际输出文件的完整路径，点击后在文件管理器中定位；序号为 0–9 的随机数字。较长路径应通过换行或可滚动区域完整访问，布局不固定为设计稿中的示例地址。
- 保留 `EXIT`、`NEXT` 的文案、外框及位置，字形使用无描边白色填充。`EXIT` 返回欢迎页，`NEXT` / Escape 返回主工作区并保留参数与历史。背景使用当前工作区的模糊快照与半透明遮罩；窗口随主窗口移动及缩放，进入渐显遵循动画设置。文件管理器仅由路径链接显式打开。
- 导出设置、模型导入、动画设置、项目说明、直方图、浮动面板以及提示、警告、错误和确认窗口共用纸面容器：白底、蓝色细边、深色胶囊标题、点阵、三色圆点、灰阶插图。标题区可拖动，右下手柄可缩放；长内容滚动，确认与取消固定于底部。系统文件选择器保持系统样式。补充窗口的运行度量见[视觉梯度](VISUAL-SCALE.md#二级窗口运行度量)。

## 通用组件与交互

| 组件 | 统一规则 |
| --- | --- |
| 面板 | 白底、蓝色 `border.panel` 描边、`radius.panel` 圆角及柔和阴影；同级普通面板使用同一角色。 |
| 分组标题 | 深灰或黑色胶囊条，`text.section` 白字；运行端按表单修订统一高度和内边界，源路径与测量独立保存。 |
| 主按钮 | 深色圆角矩形、白色文字及原稿阴影；同页同级按钮的外框高度与基线一致，各页保持原稿尺寸。 |
| 次按钮与下拉框 | 白底、蓝色细边和 `radius.control`；普通文字统一为 `text.control`。运行外框与文字留白采用后续表单修订，原稿 `formControl` 尺寸保留为参考。 |
| 滑块 | 蓝色已填充段、灰色未填充段、白底蓝边滑块；右侧数值完整显示并支持键盘输入。 |
| 复选框 | 使用统一的复选框外框和 `radius.checkbox`；点击范围包含标签。 |
| 滚动条 | 按原稿短边半径规则绘制，使用独立预留列，避免覆盖参数值。 |
| 窗口三点 | 黑、蓝、红圆点为装饰，暂不绑定操作。 |
| 焦点与禁用 | 键盘焦点使用独立的 `border.focus` 外环，不改变外框或内容尺寸；禁用状态保持字号、几何和线宽。状态色在实施中统一校准。 |

du 为与 PDF 原始 pt 同量值的设计单位，不直接作为 Qt 点数或逻辑像素；统一换算及字阶表见视觉梯度规范。品牌及展示标题的源文字轮廓和背景装饰线不套用普通控件边框档位；英文操作按钮不绘制字形描边。

预览区与控制卡片保留独立打开、移动、缩放及归位能力；现有操作见[图文说明](浮动窗口说明.md)。新版七处浮动部件使用独立窗口及原位恢复入口；黑夜模式沿用既有浮动实现。空画布鸟群、主题切换、卡片倾斜及设置项遵循用户配置。倾斜仅作用于卡片，小按钮不倾斜。

## 缩放与排版约束

- 画板基准为 4096 × 2160，工作区控件换算比例固定为 `1/3`。各背景图层独立缩放。左红带保持逻辑宽度并贯穿高度，顶部参考线延展，左右波纹等比锚定，右上方块保持逻辑尺寸，底部蓝梯形三段绘制以保留斜边与竖向渐变；策略见[背景数据](../../app/assets/workspace/background.json)。系统 DPI 缩放由 Qt 处理。
- 窗口变化或拖动预览分隔手柄时，调整的是视口尺寸，不拉伸图片。首次载入按等比覆盖建立基准；之后保留缩放和平移。直接滚轮缩放、中键平移，双击左键按当前视口容纳全图；右键可放大、缩小、适应窗口、查看实际预览像素、重置视图或还原分区。
- 历史设置与参数卡片固定宽度，高度上限为底部 IMPORT / EXPORT 按钮实体顶边前 22 逻辑 px；默认高度比例为 1。底部手柄可分别调整卡片高度，最短高度为历史 380、参数 340 逻辑 px。增加历史卡片高度时加高列表并下移设置组，参数卡片则加高滚动视口。浮动时隐藏页面高度手柄，改由独立窗口调整尺寸。全部面板使用九宫格绘制保留圆角、描边和阴影。
- 高度比例及两处分区比例写入设置，窗口变化时重新计算可用尺寸；字体、面板宽度、表单内边距和列网格保持原逻辑值。操作及复位快捷键见[当前窗口与预览规则](INTERACTION-FLOW.md#当前窗口与预览规则)，设置键见设计参数清单。
- 完整参数面板最小宽度为 302 逻辑 px，包含 267 逻辑 px 表单、视口内边距及滚动条；对应纸面浮动窗口最小宽度为 398 逻辑 px，包含 302 px 面板、左右各 12 px 内容留白及总计 72 px 窗口外壳。主工作区仍沿用原稿约 312 逻辑 px 的面板宽度。这些为后续运行约束，完整表单的纵向内容通过滚动访问。
- 卡片滚轮缓动与触控板像素滚动遵循[动效与操作反馈](INTERACTION-FLOW.md#动效与操作反馈)。
- IMPORT / EXPORT 保持共同基线及前景层级。浅色工作区最小尺寸为 900 × 640 逻辑 px；页面栈仅采用当前页约束，隐藏的黑夜页面不限制浅色窗口。不自动纵向重排；原稿参考高度为 720 逻辑 px，运行卡片高度不再固定为源测量值。

## 验收
