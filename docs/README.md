## 维护约定

- 用户可调范围与步长在[参数主表](../README.md#参数范围与精确输入)维护。算法说明描述参数对计算的影响，功能参考描述操作入口和回退行为。
- 视觉尺寸以设计目录的参数清单为准，源稿测量与运行时修订分开记录。交互决策以流程文档已填写的答复为准。
- 变更渲染步骤时复核算法说明，再生成对应图例和源码指纹。检查报告注明日期、环境、实际运行的路径及未测部分。历史测量保留原条件。
- 项目文档以源码目录为准。`github-upload` 为同步副本。依赖说明、第三方许可证及已构建程序内的文档随各自版本管理。

## 版本与构建

版本号取自 `app/version.py` 的 `__version__`，版本名称取自 `app/main.py` 的 `APP_EDITION`。准备发布时，将更新日志中的未发布条目归入对应版本，按源码版本打 `vX.Y.Z` 标签。

推送版本标签会触发 Windows 启动自检、轻量版构建及 AI 版构建。轻量版构建为必需步骤，AI 版允许单独失败。工作流把成功生成的压缩包附加到 GitHub Release。手动触发只执行构建阶段。发布二进制通过 Release 附件分发。[发布工作流](../.github/workflows/release.yml) · [本地构建](../README.md#构建与文档)
